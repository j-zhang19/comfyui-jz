# comfyui-jz

Personal node pack. Everything lives under the `JZ/` category.

- `JZ/gemini` — Gemini image generation via Vertex/GLA (outpainting), composite-back
- `JZ/padding` — aspect/resolution padding calculator + pad/unpad
- Node class keys are unchanged from ComfyUI-Outpainting-Gemini, so existing
  workflows keep working.
